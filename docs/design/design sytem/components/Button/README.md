Ana eylem, ikincil eylem ve daire ikon düğmeleri.

- `m-btn m-btn--primary`: ekranda tek ana eylem (Kanıt yükle, Oluştur, Onayla). Lime dolgu, metin `accent-ink`.
- `m-btn m-btn--secondary`: yanındaki geri alınabilir eylem (Vazgeç, Reddet).
- `m-circle`: 44px daire ikon düğmesi (ara, filtre, tarih iste, hatırlat). `m-circle--accent` yalnızca sayfadaki "yeni" eylemi içindir.
- `m-glassbtn`: cam daire; yalnızca üst çubuktaki menü düğmesi.

Sağlaman gerekenler: etiket ya da ikon düğmelerinde `aria-label`. Basınca `scale(.96)`; ek hareket ekleme.
Yapma: bir satırda iki lime düğme; ikon düğmesini 44px altına küçültmek.
