Mesaja basılı tutunca açılan işlem sayfası.

- Sıra: tepki çubuğu (4 SVG, mesaj başına bir seçim), mesajdaki atıfların yatay hap satırı, 4'lü hızlı ızgara (Yanıtla, Kopyala, Sabitle, Düzenle), altta liste (Anket sonuçları, Göreve dönüştür, Sil).
- Düzenle yalnızca kendi mesajında; Anket sonuçları yalnızca ankette görünür. Sil `danger`.

Yapma: atıfları tek tek satır yapıp sayfayı şişirmek; hap satırı yeterli.
