Yapışkan, bulanık cam üst çubuk; kök sayfalarda marka, detay sayfalarında geri ve soluk kod taşır.

- Kök: logo, `RoketPortal` (`m-brand`), altında program satırı (`m-program`, ör. Şanlıurfa Teknofest), bildirim zili ve cam menü dairesi (çekmeceyi açar).
- Detay: `Geri` düğmesi, sola yaslı soluk kod (`m-code`, `ink-muted`), sağda en çok iki ikon (düzenle, diğer).
- Arka plan `glass-bar` + `blur(var(--m-blur-bar)) saturate(1.4)`; içerik altından bulanıklaşarak geçer.

Sağlaman gerekenler: kodu veya program adını; geri işlevini (yığından bir adım geri). Detayda başlığı ortalama, her zaman sola yasla.
