Eşit sütunlu hap sekmeler; seçili sekmenin arkasında kayan bir başparmak vardır.

- Kap `m-tabs`, `--n` sütun sayısı, `--i` seçili sıra. Başparmak `left` ile kayar (`--m-ease-spring`, .42s, hafif taşma).
- Yükseklik 36px, etiket `m-tab`; sayaç `m-tabs__n` mono 11px.
- Detay sayfalarında `m-tabstrip` içinde üst çubuğun altına (top 64px) yapışır.

Sağlaman gerekenler: `role="tab"`, `aria-selected`, ilgili `tabpanel`. Tüm detay sayfalarında aynı bileşen kullanılır; alt çizgili sekme yok.
