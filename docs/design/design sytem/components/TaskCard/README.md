Görev listesindeki kart: kod, koordinatörlük, durum, başlık, tarih kutusu ve atanan.

- Başlık en çok iki satır (`m-card-title`). Bitiş tarihi geçtiyse tarih `danger`, altta `m-late` hapı ("98 gün gecikti").
- Tarih kutusu `bg-raised` üzerinde üç sütun: başlangıç, bitiş, öncelik (`m-prio`, `data-level` 1–3).
- Kartın tamamı tek bağlantıdır; basınca `scale(.985)`.

Sağlaman gerekenler: görev kodu, durum noktası rengi (`gp-*` değil `violet`/`gold`/`danger`/`accent-text`), atanan baş harfleri.
